    Donwload Sentinel-3 LST and SYN Products¶

    In this example, some Sentinel-3 LST and SYN products are downloaded and their data plotted.

    Import Packages¶

    In [1]:
    Copied! 
    from pathlib import Path

import cartopy.crs as ccrs
import matplotlib.pyplot as plt

from s3lst_ds.data_download.download_sentinel3 import download_products
from s3lst_ds.data_download.download_sentinel3_config import Sentinel3Config
from s3lst_ds.data_reading.s3_reader import Sen3Loader
    from pathlib import Path import cartopy.crs as ccrs import matplotlib.pyplot as plt from s3lst_ds.data_download.download_sentinel3 import download_products from s3lst_ds.data_download.download_sentinel3_config import Sentinel3Config from s3lst_ds.data_reading.s3_reader import Sen3Loader

    Download Products¶

    Configure¶

    With the configuration below, one intends to:

    • donwload NT (Non-Time Critical) Sentinel-3 Level-2LST and SYN products;
    • to directory ./data;
    • for two date-ranges - from 2020-07-18 to 2020-07-19, and from 2021-07-16 to 2021-07-26;
    • for the Lisbon metropolitan area (represented by a WKT string);
    • solely products with a cloud cover fraction not larger than 30 % are to be considered;
    • the products are to be processed, that is, georeferenced and subset to the bands and area of interest - using esa-snappy;
    • the clouds are to be masked out;
    • the whole procedure is to be logged into the terminal.
    In [2]:
    Copied! 
    download_config = Sentinel3Config(
    out_dir=Path("./data"),
    timeliness="NT",
    start_sensing_dates=["2020-07-18", "2021-07-16"],
    end_sensing_dates=["2020-07-19", "2021-07-26"],
    geometry_aoi=(
        "POLYGON ((-9.53 38.57, -9.05 38.57, -9.05 38.92, -9.53 38.92, -9.53 38.57))"
    ),
    cloud_cover_max_aoi=30,
    process=True,
    process_engine="snappy",
    mask_clouds=True,
    log_mode="console",
)
    download_config = Sentinel3Config( out_dir=Path("./data"), timeliness="NT", start_sensing_dates=["2020-07-18", "2021-07-16"], end_sensing_dates=["2020-07-19", "2021-07-26"], geometry_aoi=( "POLYGON ((-9.53 38.57, -9.05 38.57, -9.05 38.92, -9.53 38.92, -9.53 38.57))" ), cloud_cover_max_aoi=30, process=True, process_engine="snappy", mask_clouds=True, log_mode="console", )
